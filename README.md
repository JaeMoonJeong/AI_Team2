## 🚀 2. 프로젝트 목표

-   **미션:** 유저가 촬영한 이미지 속에서 **최대 4개의 알약 이름(Class)과 위치(Bounding Box)**를 검출하는 모델 구현
-   **목표:** Kaggle Private Leaderboard를 통해 모델 성능을 지속적으로 개선하고, 그 과정을 트래킹
-   **핵심 기술:** Object Detection (객체 탐지)
